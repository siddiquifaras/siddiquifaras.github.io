I'm a software engineer building AI systems for production: agentic workflows, LLM inference, graph neural networks, and the GPU and DevOps infrastructure they run on. I'm a founding engineer at CVision, an applied-AI consultancy in Islamabad, where the systems I delivered brought in more than US$70,000 in client revenue in my first six months.

Alongside that, I research neuromorphic computing and event-based vision. I wrote Frames2Py, an open-source library that lets other code watch an event camera live while the main loop keeps running at more than 20 million events per second. For TALON, Type 1 Compute's neuromorphic computing SDK, I built the simulation engine, the IR visualiser and a binary encoder that compresses spiking neural networks about a thousandfold. I've also had fixes merged into the Neuromorphic Intermediate Representation (NIR), the shared format for moving spiking networks between simulators and chips.

02Selected projects

Frames2Py

Open-source Python library · 2026

Lets other code watch an event camera live without slowing down the loop that consumes it. A producer thread feeds events to an Engine, which accumulates them and publishes read-only snapshots. Any number of consumers read the latest snapshot at their own pace, and the producer never waits for them.

TALON

Neuromorphic computing SDK · Type 1 Compute

TALON (Tactical AI at Low-power On-device Nodes) takes PyTorch and snnTorch models to neuromorphic hardware and Xilinx Zynq FPGAs. Like ONNX, it turns a model into an IR graph, then into a portable .t1c file. I built the simulation engine, the IR visualiser and the binary encoder. The encoder stores a ten-layer network in about 200 bytes instead of 200 KB.

03Open-source contributions

I contribute upstream to open-source projects in neuromorphic computing and in machine learning on constrained hardware. In the Neuromorphic Intermediate Representation, my two merged fixes repaired a type-check guard that could never fire, and added validation that reports dangling and duplicate graph edges by name, so they no longer surface later as confusing type-inference failures. For PicoLM, which runs a one-billion-parameter language model on a board with 256 MB of RAM, I proposed NEON-vectorised flash attention using the hardware FP16 conversions on AArch64.
