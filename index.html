AI systems that hold up in production

I'm Faras Siddiqui, founding engineer at CVision. I build agent runtimes, LLM inference and serving, and the infrastructure that keeps them reliable, from cloud GPUs to air-gapped networks and edge hardware.

What I work on

I build and deploy applied AI systems that have to work outside the usual cloud setup: across on-premise GPU clusters that I design to serve the load where it's needed, inside air-gapped networks where no external API is allowed, and on edge hardware with tight memory, compute and energy budgets. Most of that work is AI infrastructure: agent architectures, LLM inference and serving, evaluation, and the deployment pipelines around them.

Alongside it I work on neuromorphic computing and event-based vision, mainly the tooling that gets spiking neural networks and event-camera data into usable software.

Selected work

  • Agent runtime for an air-gapped AI coding IDE — the agent runtime, GPU cluster scheduling, model evaluation and routing, and security guardrails for an on-premises coding platform at Noah Labs
  • Agentic systems at CVision — agentic LLM workflows, RAG, GNN-based reasoning, and knowledge graphs with graph-backed memory in Neo4j, across cloud, edge and industrial deployments
  • TALON — a neuromorphic SDK that takes spiking neural networks from PyTorch down to FPGA hardware
  • frames2py — an open-source library for streaming event-camera data at more than 20 million events per second
