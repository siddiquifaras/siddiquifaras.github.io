# About

I'm Faras Siddiqui, a software engineer who builds and deploys applied AI systems. I'm a founding engineer at [CVision](https://www.cvision.dev), where I set up the company's core AI infrastructure, lead production deployments on cloud, edge and industrial stacks, and grew the engineering team to 7. CVision reached $150K+ in first-year revenue and $2M+ in partner deal value, working with industrial, research-led, SME, and YC- and Antler-backed partners.

Most of my work is AI infrastructure: agent architectures, LLM inference and serving, evaluation, and the pipelines that keep them reliable. A lot of it runs under hard constraints: air-gapped networks where no cloud API is allowed, and edge hardware with tight memory, compute and energy budgets. At Noah Labs I built the core AI infrastructure for an on-premises, air-gapped AI coding platform, working directly with the CTO: the agent runtime, GPU cluster scheduling and inference orchestration with vLLM, model evaluation and routing, and the security guardrails around autonomous agents.

I also work on neuromorphic computing and event-based vision. I built all seven packages of [TALON](https://siddiquifaras.github.io/projects.html#talon), an SDK that takes spiking neural networks from PyTorch down to FPGA hardware, and I wrote [frames2py](https://siddiquifaras.github.io/projects.html#frames2py), an open-source library for streaming event-camera data. I've contributed fixes upstream to the [Neuromorphic Intermediate Representation](https://github.com/neuromorphs/NIR).

I'm open to relocation within Europe.
